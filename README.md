# auto-nicotine-downloader
A simple Nicotine+ plugin written in Python that automatically downloads albums choosing the best quality

# Installation
1. Download all files
2. Ensure that [Python]([url](https://www.python.org/downloads/)) is installed
3. Put them into "%APPDATA%\nicotine\plugins\album_downloader" (or a folder that Nicotine can read)
4. Add the plugin in Nicotine -> Preferences -> Plugins -> Add plugins (select init.py)

# Usage
Write "album: [album name] - [artist]" in the search bar and press enter. The download should start in less than 20 seconds.
"/album-list" to show a few options
"/album-pick 2" to download the second option

You can also use chats instead of the search bar
